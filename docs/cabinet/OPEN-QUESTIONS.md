### 4.1 Передача заявки подрядчику — предложение (05.11.2026)

Во второй этап не входит (`docs/DECISIONS.md`: заявки принимаем мы). Схема на момент включения,
чтобы раздел «Заявки» кабинета (макет — демо ветки `claude/cabinet-ui`, `/profi/moi/zayavki/?demo`) лёг без переделки:

1. **Заявка приходит к нам, как сейчас** (`POST /api/wed/lead` → группа модерации + письмо нам).
   Модератор отсекает спам и нажимает «Передать» — подрядчик берётся из карточки, с которой пришла заявка (`sourceUrl`).
   Автопередачу без модератора включаем позже, когда спама будет понятно сколько.
2. **Подрядчику — уведомление без личных данных пары** по `notifyVendor` (мессенджер входа и/или почта):
   «Новая заявка на карточку „…“ — откройте кабинет». Telegram — иностранный сервис, имя и телефон туда не уходят
   (решение 20.10); то же правило держим для MAX и почты, чтобы не было трёх разных политик.
3. **В кабинете** — имя, дата свадьбы, сообщение; телефон — по кнопке «Показать телефон» с записью в журнал
   открытий. Этот журнал — основа списаний третьего этапа (передача заявки — платное событие, как «Показать контакты»).
4. **Блокер — согласие пары на передачу ПДн конкретному подрядчику**: отдельная галочка в форме заявки,
   текст юриста (вопрос №1). Без неё данные пары подрядчику не передаём.
5. **Схема** (миграция при включении): у `leads` — `vendor`, `card`, `status` (new → forwarded → opened → closed),
   `forwardedAt`; журнал `lead_views` (кто, когда, IP). Подрядчик читает только свои заявки, правило коллекции,
   не проверка в коде; пишет в `leads` по-прежнему только маршрут.

Решить: (а) включаем в конце второго этапа без денег или вместе с третьим; (б) модератор передаёт руками или сразу автоматически.

## 6. Риски, за которыми следим

- Тексты юриста — самое длинное по времени, блокируют регистрацию: заказать на неделе 1.
- Память сервера 1,9 ГБ: без тарифа 4 ГБ сборку страниц сервером не включаем.
- Письма с кодом в спаме: проверка mail-tester и трёх почт до пилота.
- Владелец в пилоте урезает богатый текст: ловит экран «что поменялось».
- Фото из кабинета без копии: копию включаем вместе с S3, до первых загрузок.
