## Кабинет подрядчика — хвосты первого шага (05.10, CABINET.md)

База и правила модерации готовы (`pb/pb_hooks`, проверка —
`scripts/pb-test-cabinet.mjs`). Не сделано и всплывёт позже:

- **HEIC не принимается** — `revisions.photos` берёт только jpg/png/webp.
  Safari на айфоне сам отдаёт JPEG, но с Mac или из «Файлов» придёт `.heic`
  → подрядчик увидит отказ. Конвертировать при загрузке (вместе с imgproxy).
- **Размер кадра (от 1600 px) не проверяется на сервере** — PocketBase
  из хука не читает размеры. Проверка в форме кабинета (браузер знает
  `naturalWidth`) + на сервере, когда встанет обработка фото.
- **Геометка (EXIF) не срезается** — оригиналы карточки сейчас открыты
  по `/api/files`. Когда сайт пойдёт через imgproxy (он срезает метаданные),
  поле `photos` у карточек закрыть (`protected`).
- **Категория и ответы на фильтры не сверяются со `specialist-filters.ts`**
  — хук знает только формат slug. Сверять по дампу `filters-dump.mjs`,
  иначе опечатка в категории даст карточку вне каталога.
- **«Это моя карточка»** — у карточек, заведённых нами (`owner` пуст),
  владельца ставит модератор руками в админке. Сценарий заявки на
  владение — к открытию для подрядчиков.
- **Брошенные черновики держат адрес** вечно. Если начнут мешать —
  чистка черновиков старше N дней.
- **Площадки из кабинета на сайт не выходят** (26.10) — `pb-pull-cabinet.mjs`
  забирает только подрядчиков: страница площадки собирается из блоков
  (`VenueBlock`), анкета их пока не даёт. Одобренная площадка живёт в базе.
- **Выкладка после одобрения — руками** (Actions → Deploy → Run workflow).
  Автоматически: хук одобрения дёргает `workflow_dispatch` (нужен токен
  GitHub на сервере) — или сразу сборка страниц сервером (недели 3–5).
- **Письма подрядчику молчат**, пока нет Яндекс 360 (хук глотает ошибку
  SMTP). Статус и причина возврата видны в кабинете; уведомление
  подрядчику в Telegram от бота — когда понадобится.
- **Кабинет живёт в `localStorage`** (токен 30 дней). Для рабочего
  инструмента приемлемо; при переходе на `profi.` — httpOnly-кука через
  свой маршрут, если понадобится.
- **Уведомление «На проверку» в группу** (прогон 26.10 — не пришло): с 27.10
  хук пишет в лог базы код и ответ Telegram при отказе. Выложить хуки и
  посмотреть `_logs` после следующей отправки.
- **Площадки из кабинета на сайт** — анкета площадки (залы, условия, вопросы)
  с 27.10 полная, но страницу из блоков из неё ещё не собираем.
- **«Заявки» в админке — заглушка прототипа** (Go Show, выдуманные
  счётчики), живая очередь — «Модерация» → «Из базы». Модератор в первый
  раз пошёл в «Заявки» и не нашёл карточку: одна очередь, заглушки убрать.


- **Прайс: «как это выглядит на сайте»** (Никита, 27.10) — в анкете
