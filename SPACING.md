# Пульт отступов и токенов

Все расстояния — токены в `:root` (`src/styles/global.css`). В компонентах числа не хардкодим.

| Ручка | Что делает | Диапазон |
|---|---|---|
| `--page-max` | ширина контента | 1100–1280px |
| `--page-max-wide` | широкий контейнер для фото-полос | 1360–1600px |
| `--gutter` | боковые поля до края экрана | clamp 20–48px |
| `--section-gap` | полный вертикальный разрыв секции | clamp 56–120px |
| `--section-gap-tight` | поджатый вариант | clamp 32–64px |
| `--s-2…--s-8` | шаги внутри блоков | 8–64px |
| `--radius-*` | скругления: media / card / ui / pill | крутится в одном месте |
| `--dur-*`, `--ease-*` | моушн: длительности и кривые | см. global.css |

Правила:
- `.section` несёт `padding-block: var(--section-gap)` — соседние секции НЕ удваивают
  разрыв только если у одной из них `.section--flush-top`; следить при стыковке.
- Точечные отклонения — модификаторами (`.section--tight`, `.section--flush-top`),
  а не правкой общего токена.
- Меры строк — `--measure-lead/text/head` в `ch`, ставятся на сам текстовый элемент.
- «Поменять поля/расстояния/скругления» = крутить токен, а не отдельные секции.

Перенос на следующий сайт: скопировать блок токенов из `global.css` + этот файл.
