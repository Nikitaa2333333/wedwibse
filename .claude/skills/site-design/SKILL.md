# site-design — витрина WED Secrets

Источники: `DESIGN.md` (токены, реестр, анатомия страниц, снятое), `SPACING.md` (сетка), `CLAUDE.md` (законы),
`docs/TRAPS.md`, `docs/IMAGES.md`. Здесь — порядок действий и правила, которые чаще всего нарушают.
Глобальные правила пользователя (капс, жирность в наборе, мера строки, контраст) действуют всегда; ниже только их приложение к проекту.

## Перед правкой

1. Найти элемент в реестре `DESIGN.md` §2 и в `src/styles/global.css`. Есть похожий — использовать, не рисовать второй.
2. Просят «поменять расстояния / кегль / радиус» — править токен, а не секции. Нужна новая ручка — новый токен с комментарием о диапазоне.
3. Прочитать раздел `DESIGN.md` про страницу, которую правите (§3 подрядчик, §4 площадка, §5 первый экран, §6 каталог, §7 главная).
4. «Снято, не возвращать» — `DESIGN.md` §9. Сверяться до того, как предлагать.

## Токены и реестр

- Любое значение (цвет, отступ, радиус, длительность, кегль) — токен из `global.css`. Хардкод запрещён.
- Группы токенов: бумага/чернила (`--paper`, `--ink`, `--surface`), шрифты, кегли `--fs-*`, веса `--w-*` (четыре, своих `font-weight` нет),
  межстрочное `--lh-*`, отступы `--section-gap`, `--gutter`, шаг `--s-1…--s-8`, меры `--measure-*`, радиусы `--radius-*`.
- Реестр: `.pill` (единственная кнопка-действие), `.chip` (выбор), `.plates` (короткие факты), `.list` (единственный маркер),
  `.rows` (метка — значение), `.shot` (кадр внутри страницы), `.media--bleed` (кадр во всю ширину), `.sheet`, `.theme-dark`,
  `.hero-btn`, `.save`. Новый элемент сразу в `global.css`, не в стилях страницы.
- Отступы через `.container` / `.section` и переменные; точечные отклонения — модификаторами (`.section--tight`).
  Дыра между блоками — сначала проверить удвоенный `--section-gap`. После расширения `--page-max` проверить блоки с картинками и формами.

## Что нельзя

- Текст на фото. Затемнений нет (`.veil` удалён). На кадре только сердце `.save` и кнопки `.hero-btn`. Стекло — только у панелей, всплывающих по нажатию.
- Плашка в плашке: одна подложка, содержимое прямо в ней; внутри отделяем отступом и кеглем.
- Цветные заливки секций, бирки-надзаголовки, номера (01, 02), линии между пунктами и фактами. Линии только в таблицах цен.
- Факты «да/нет» строками («Кухня: своя») — фразой в тексте.
- Капс (`text-transform: uppercase`, small-caps, набранный руками); исключения — аббревиатуры и марки.
- Жирность внутри фразы (`<b>`, `<strong>`, `font-weight` на селекторах абзацев). Выделение только `<mark>`: короткая фраза в одну строку, одна-две на секцию. В карточках подрядчиков выделения нет.
- Приглушённый текст: opacity, серый, «мягкие» оттенки белого. Иерархия — кеглем, заголовком, акцентом. Исключения (плейсхолдеры, декор) проговорить вслух.
- Антиква (Cormorant) мелким кеглем. Имена в карточках, имена пунктов, метки — жирный Onest.
- `text-align: center` на наборном тексте; текст без `max-width` в `ch` на самом элементе.

## Типографика и меры

- Наборный текст 68–78 знаков в строке, лид 56–64, заголовок страницы 24–30. Меру ставить на сам текстовый элемент, не на контейнер.
- Мера заголовка — только крупным h1/h2; подзаголовки укладываются сами. Снял плашку — верни меру тексту.
- Межстрочное: мелкая подпись в 2–3 слова — `--lh-caption` (1.1); фраза в несколько строк — `--lh-body`.
- Перечисления: маркер `.list` на чистых перечислениях; пункт в несколько строк отбивается около 28 px, короткие однострочные — 5–8 px.
- Русская типографика: неразрывные пробелы после предлогов и между числом и единицей, «ёлочки». Цены склеены целиком («12 000 ₽», «— 7 000 ₽», «от 40 000 ₽»): текст из данных и кабинета выводить через `glue()` из `src/lib/typo.ts` (заказчик, 09.11.2026).

## Mobile-first

- Базовая вёрстка под 375–430 px; расширение только `min-width`.
- На мобилке моушн только transform/opacity; без blur/filter-анимаций, канвасов, параллакса.
- «Вау» только в `@media (min-width: 1024px) and (pointer: fine)`; ховер только в `@media (hover: hover)`.
- Появлений блоков при прокрутке нет. Только `--ease-out` / `--ease-inout`, linear не использовать. `prefers-reduced-motion` уважается глобально.
- Ленты с нативным скроллом не объявляют `touch-action` (кроме `PhotoRail`).
- Навигация: потомок получает `BackButton` (чернильный квадрат `.hero-btn`), крошки текстом нет; разделы — `BottomDock` (таб-бар / рельс на ПК).
- Мерить на экране пользователя: Windows 150 %, то есть около 1280 CSS-px. Правка `max-width` выше этого незаметна — сказать прямо.

## Картинки

- Фото карточек, галерей, героев — только `<Image>` / `<Picture>` из `astro:assets`; источник `src/assets/`, путь через `resolveImage()`.
- `widths` — роль из `IMG_WIDTHS` (`hero`, `wide`, `card`, `tile`, `stage`, `thumb`); `sizes` — реальная доля экрана на каждом брейкпоинте,
  совпадающая с `grid-template-columns`. Новая роль — в `src/lib/images.ts`.
- Первый экран карточки — окно 4:5 (`--stage-ratio`): портрет и квадрат `cover`, горизонталь `contain`. Вертикальность — `isPortrait()` из `lib/media.ts`.
- Не пережимать файл перед укладкой в `src/assets`; новую пачку — `magick identify`. Портрет автора — поле `avatar`, рисует `Avatar`.
- Ролики — `docs/VIDEO.md`; звука в выдаче нет.

## Ловушки (`docs/TRAPS.md`)

- У вертикального скролл-бокса `overflow-x: clip`; полю в grid — `min-width: 0`; всплывашки только через `bindSheet` / `.sheet`.
- Чужие внутренности через `:global()` снаружи не переопределять — проп на компоненте.
- Процентная высота во flex — `flex: 1 1 0`.
- Сайт открыт для поиска: служебная или черновая страница ставит `noindex`.

## Перед тем как отдать

1. Собрать то, что менялось; полную `astro build` ради мелочи не гонять.
2. Свой снимок для проверки: `node scripts/shot.mjs <путь> <селектор> research/shots/x.png` на ширине 390 px. Пользователю пачки снимков не слать.
3. Дев-сервер с `--host 127.0.0.1` и своим портом; после серии правок стилей перезапустить; погасить по PID.
4. Сказать, куда смотреть. Находку и новое правило записать в `DESIGN.md` (текущее состояние) или `BACKLOG.md` (хвост).
